- Source validation: [public candidate run](https://github.com/vixttha/Version-Issues-Hub/actions/runs/45330061978)

The project archive workflow builds a Graphify map from the exact public VIB source, imports the candidate into a disposable Veraphify archive, verifies the digest, and checks all five implementation citations. Its output is candidate evidence only, not five release archives and not a merge verdict. Find the output on the [Actions page](https://github.com/vixttha/Version-Issues-Hub/actions/workflows/vib-veraphify.yml) after a successful run; artifact retention is limited to 90 days.

Keep accepted archive pins and bytes separately before claiming durable archival. Never replace an accepted version's existing archive. No private source, credentials, template edits or product branch mutations are permitted. GitHub issues and the VIB package remain authoritative.
