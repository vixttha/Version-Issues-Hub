# Version-Issues-Hub Ideas and Features

Start with the [Ideas index](ideas/INDEX.md) and [Features index](features/INDEX.md). This catalog supports [issue #1](https://github.com/vixttha/Version-Issues-Hub/issues/1), the first checkpoint on the internal `v0.0.0` line. The [draft workflow](https://github.com/vixttha/Version-Issues-Hub/pull/2) defines acceptance and the later merge-enforcement pilot.

The catalog starts from the [Provenistem v0.0.2 package](https://github.com/vixttha/Provenistem/tree/e36fcd6d12633395e9b573228c0797ade9e775b0/packages/provenistem). Run `python tools/library.py check` for this populated workspace. Public CI checks the starter's tests on its pinned upstream snapshot, then validates the project catalog separately.

The Linux Graphify artifact maps planned features to their acceptance criteria, linked ideas, and catalog validation at the tested checkout. GitHub Issues and PRs retain product implementation, verification, and owner decisions.
