# Review and decisions

For each decision record the owner direction, agent interpretation, alternatives shown, selected asset revision, and approval scope if given. Keep historical receipts and indicate which assets can be adopted now.

Review exact text, silhouette at target size, spacing, light and dark backgrounds, transparent edges, color contrast in surrounding UI, grayscale behavior, visual similarity, provenance and downstream usage terms. Record the preview or evidence for each check, and mark checks pending when evidence is missing.

Before handoff, run `python3 brand-identity/verify.py --ready-for-handoff` from the repository root. Before rollout, list destinations, the maintainer decision, and the preceding asset or text to restore if needed. Link the final [manifest](../09-assets/manifest.json).
