# Reuse and attribution

The [root MIT license](../LICENSE) covers Veraphify-authored source code and tests,
including Veraphify-authored changes to imported software. Preserve the copyright
and permission notices when redistributing copies or substantial portions.

| Material | Applicable notice |
| --- | --- |
| Veraphify-authored code and tests | [Root MIT license](../LICENSE). The CLI and Test Vault include first-party work. |
| Lydite-derived runtime support | Preserve the [Lydite MIT notice](../lib/LYDITE-LICENSE) with the CLI's evidence inspector and profile. The upstream [installed-files inventory](https://github.com/vixttha/Veraphify/blob/ed5650085e33cf142a37de695757a4df999a7cf3/test-vault/README.md#installed-files) describes their origin. |
| Graphify and external dependencies | Use the terms supplied with each upstream project or dependency. The [adopter walkthrough](adopter-walkthrough.md) identifies the pinned producer. |

Product names, logos, and wordmarks fall outside this software license. Evidence
archives preserve adopter source bytes. Follow the terms of the source project
and each included dependency when reusing or distributing those bytes.

This installation is based on the [v0.0.9 preview source](https://github.com/vixttha/Veraphify/tree/ed5650085e33cf142a37de695757a4df999a7cf3).
