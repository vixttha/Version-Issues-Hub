# v0.0.0.10 — Historical package compatibility

## Historical package compatibility

The live Phase 4 public-runner trial on v0.0.0.9 exposed an older BART source pin whose package predates Standard validation. Source mapping is now read as a literal from the exact pinned installer source and constrained to recognized file paths. The installed manifest still binds every source file by SHA-256. No package code is executed to discover the map. Existing adopters are not upgraded automatically. Live acceptance and simulated regressions must pass; a fresh process is not an independent LLM trial.
