# v0.0.0.13 — Fresh CLI and recovery acceptance

## Fresh CLI lifecycle acceptance

The test invokes actual install and lifecycle CLI entry points against real disposable Git repositories using a simulated GitHub API. It initializes a product with no VIB branch, runs dry-run and apply, upgrades the package, verifies a durable exact archive, manually removes only the disposable fixture branch using an expected-old ref, restores it from the archive, and verifies ledger/handoff blob identity and product ref. A competing writer during upgrade must be rejected by a non-force update. The live public-runner job separately exercises the CLI in read-only mode against README HQ, using the documented v0.0.6 planning baseline, without creating an installation or modifying its existing assignments. No live branch deletion, GitHub CLI apply on a newly created remote repo, or independent LLM trial is implied.
