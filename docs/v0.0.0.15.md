## Recovering a confirmed remote installation

Live pilot run 45338996332 stopped at immediate ref readback even though its create operation later became visible. Independently confirmed installation ec6d1584c28015ab15e5ed94e8eabe67a6181bcd with parent equal to original clouds main, correct manifest and empty state. A successful write now receives bounded GET-only confirmation retries for the exact expected revision, tolerating absence for create or the known previous revision for update. Unexpected revisions and exhausted retries fail closed; never repeat writes or force. Resume the existing branch at the exact observed SHA and validate its full tree and provenance. Original CLI apply returned failure, so do not count a corrected fresh remote install as passed solely from recovery. Actual live upgrade and archival preparation are separate controls.
