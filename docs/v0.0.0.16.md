# v0.0.0.16 — Safe API failure diagnostics

## Diagnose without repeating mutations

The second clouds pilot recovered its initial branch and passed the dry-run upgrade, then GitHub returned HTTP 500 during apply. The original API error did not identify the operation. The dedicated ref remained at the confirmed initial SHA. Add operation-class context, not full URLs, paths, request bodies, response bodies, or credentials. Only transient GET 500/502/503/504 receives at most two retries; mutating methods never repeat automatically. A failed or ambiguous mutation requires fresh ref/tree inspection before a separate authorized attempt. The next pilot attempt is pinned to the exact confirmed initial branch and reviewed source; preserve all prior failures. No live deletion or fresh independent model claim.
