# v0.0.0.17 — Read-only transport recovery

## Bounded transport recovery

A GitHub read timeout during live adoption was observed in run 45339477889. Only direct or URLError-wrapped TimeoutError on GET is eligible for the existing three-attempt bounded backoff. HTTP 5xx policy is unchanged. All POST/PATCH/DELETE transport errors fail without replay and require exact readback before any authorized retry. Diagnostics retain operation class only; no request URL, credentials, query or body. This does not repair the separately observed GitHub PATCH HTTP 500 on clouds or establish successful live CLI upgrade.
