# v0.0.0.19 — Concurrent adopter recovery

## Concurrent adopter recovery

The live read-only push check correctly refused a stale BART installed SHA while another project session advanced it. The acceptance harness now reloads the entire snapshot only after an observed installed-ref advance, up to three tries, and requires identical independent-process results at one revision. Other failures, disagreement or exhaustion still fail closed. This does not weaken the product's stale-write guard or modify any adopter. The old lifecycle Graphify anchor now points at a stable unique line in the same function after its signature changed. Prior fix pins remain unchanged.
