# v0.0.0.35 — Archived verification integrity

## Complete archived success evidence

Issue #71 closes a validation gap: imported or corrupted archived Head records with disposition staged or integrated could omit all candidate fields and evidence even though finish requires verification. The validator now requires fix SHA, candidate SHA, PR number and nonempty exact repository run-attempt references for these two dispositions. Existing field, URL, disposition and merged-SHA checks remain intact. Blocked, deferred and rework records may retain incomplete verification. No history rewrite or installed-package migration; this validates structure, not the truth of a CI verdict.
