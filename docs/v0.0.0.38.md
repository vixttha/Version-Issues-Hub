# v0.0.0.38 — Owner-controlled qualification (#82)

## Qualification boundary

Decision VIB-LAW-OWNER-QUALIFICATION-001: independent host trials, actual-agent benchmarking, exploratory scale/concurrency campaigns and repetition of unchanged qualification evidence are suspended until explicit owner approval. Ordinary focused regression, code review and exact-revision evidence remain permitted on standard public GitHub-hosted runners. No environment variable, workflow input, issue comment or agent assertion can enable a suspended campaign. Resumption requires a separate owner-authorized reviewed source change naming the exact campaign, revision, scope and permitted execution. The current repository intentionally provides no automatic or self-service opt-in. These are cooperative repository safeguards, not access-control guarantees against an authorized writer changing code or running historical commits.

The four historical workload/benchmark/counterexample methods in tests/test_vib53_qualification.py are retained intact and explicitly skipped; their previously executed receipts remain historical. Smaller deterministic recovery and lifecycle regression methods remain enabled. The historical standalone experiment workflow is retained as documentation under docs/qualification/, not an executable Actions workflow in new development. Historical branches are not rewritten; do not dispatch or push those refs to resume experiments. No external agents or schedules may be started for qualification. This does not claim the advanced capabilities passed.
