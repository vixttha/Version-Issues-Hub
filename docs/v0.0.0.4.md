# v0.0.0.4 — Agent-ready package candidate

## Bootstrap and handoffs

Issue [#10](https://github.com/vixttha/Version-Issues-Hub/issues/10), phase two of owner-locked #9. The installer now includes AGENTS.md, WORKFLOW.md, a read-only session inspection entry point, and an empty durable handoff record. The session tool verifies package contents against the pinned VIB source, target identity and current installed ref, then returns the current issue and phase. It supports planned and explicitly applied cooperative claims, transitions, and owner decisions via an atomic non-force update of the dedicated branch. Stale writers and a second issue are rejected. Product code and branch policy are not changed.

Acceptance includes deterministic public-runner tests for resume, conflicting claims, version baseline, exact PR head, evidence reference binding, stale leases, owner decision, and tampered package. This is a host-neutral agent contract, not a guarantee that arbitrary LLMs will obey it. Live fresh ChatGPT and independent harness trials remain phase-four acceptance. The recorded evidence URLs are not a trusted merge verdict; phase three handles enforcement.
