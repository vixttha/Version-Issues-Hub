# Agent Engineering Toolkit — working ecosystem identity and offer

Status: owner-directed commercial planning, not final name/logo approval or public launch.

## Identity

Working descriptive name: **Agent Engineering Toolkit**.
Tagline proposal: **Six independent tools. One durable engineering environment.**
Category: GitHub-native, provider-neutral modular engineering environment for compatible AI agents. Not an LLM, hosting service, agent orchestrator, or monolithic framework.

Audience: solo developers and small engineering teams using GitHub and AI coding assistants; especially projects with repeated session handoffs, unclear acceptance, lost test evidence or difficult version recovery.

## Offer

- Standalone: choose any one product; install at a reviewed pin and use without the other five.
- Complete environment: optional six independent branches, consistent discovery and install guidance, reusable public-runner acceptance. No single purchase, bundled runtime, registry or seventh tool required.
- First paid service proposal: fixed-scope repository setup and evidence audit; optional training and support. No paid execution required for ordinary use, no claims that buying support grants product authority.
- Future optional commercial services are proposals only; no price, charge, subscription, storefront, or license change established.

Demo: use a real issue in a public sample project, record accepted scope, recover the issue/version in a fresh agent, run tests, preserve a version evidence reference, update README and retain owner approval/brand records. Demonstrate standalone failure tolerance by removing one optional capability from the sample; never remove existing adopter branches without explicit approval. Present actual measured limitations as well as success.
