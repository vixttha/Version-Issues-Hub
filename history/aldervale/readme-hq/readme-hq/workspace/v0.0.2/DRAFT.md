## From draft to public README

1. Draft and test in `workspace/<version>/`. Keep candidate Markdown, visual assets, and review notes there.
2. When a candidate is approved, copy its exact bytes to `versions/<version>/README.md`. Record the changes from the previous approved version in `CHANGELOG.md` and add one row to the version history in the same commit.
3. Open or update a PR into `main` containing the approved public README and its approved assets. Check that the files and links work from the repository root. Publishing requires separate merge authorization.
