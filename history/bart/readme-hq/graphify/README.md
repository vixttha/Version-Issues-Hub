# Graphify integration

Blender-Agent Refinement Toolkit already has a separate permanent [`graphify-hq` branch](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/graphify-hq) for application-version maps, candidates, receipts, and CI.

README HQ does not copy or rewrite Graphify's application release catalog. When a public README revision is published with an approved application release, coordinate with Graphify HQ to archive the source-pinned graph separately. No application release or Graphify MCP verification is asserted by creating this README workspace.

For future HQ-template-specific visual maps, add an independently generated, verified graph and receipt with a new HQ version archive. Avoid fabricated Graphify output.
