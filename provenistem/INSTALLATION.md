# Provenistem on Veraphify

This library tracks Ideas and Features for the `Veraphify` template workspace in `vixttha/Version-Issues-Hub`. Start at the [library guide](README.md), then open the [Ideas index](ideas/INDEX.md) or [Features index](features/INDEX.md). Use the [agent guide](LIBRARY-AGENT-GUIDE.md) when passing the workspace to an LLM.

This copy was initialized from the portable Provenistem v0.0.2 package (source repository `vixttha/Provenistem`, commit `e36fcd6d12633395e9b573228c0797ade9e775b0`, path `packages/provenistem`). The catalog starts empty. Record this workspace’s own ideas, features, decisions, and evidence under `provenistem/` on the template branch. When adopting the template into another repository, start a separate local catalog with fresh IDs and evidence.

The library stays with the template branch. A product pull request can link to a pinned record or carry a separately reviewed output. Template and product versioning remain independent.
