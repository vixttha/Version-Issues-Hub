# Case and run receipt

Copy the fields into your repository's existing issue, review, or evidence system.

| Case field | Supply |
|---|---|
| Case ID and priority | Stable ID and why the case matters |
| Expected result | Observable outcome and its source |
| Setup and assertions | Representative input, procedure, and exact assertions |
| Implementation | Suite path, test command, and related issue or feature |
| State | Proposed, implemented, CI verified, or manually verified |

| Run field | Supply |
|---|---|
| Case IDs and command | Assertions actually exercised |
| Source revisions | Actual checkout, PR base/head, and merged revision when relevant |
| Runner evidence | Run and job links, attempt, OS, runtime, platform |
| Outcome | Pass, fail, skip, or blocked, including the reason |
| Retry history | Original result and what the rerun observed |
| Limits | Paths, platforms, or acceptance steps pending verification |

For a manual check, record the pinned build, environment, steps taken, observed result, and the person who performed it.
